# Identité Benfou

Sources : archive Branding BENFOU fournie par le mainteneur, logo vectoriel et monogramme F, charte indiquant Oleo Script Swash Caps et Montserrat. Accent #C0FA39 fourni explicitement.
Les SVG sont conservés sans modification et chargés depuis le plugin. Pas de script ni de ressource externe dans ces SVG.
Le CSS est limité à .amf-wrap et aux composants Audit Médias. Le logo contient sa signature en tracés vectoriels : aucune police script n'est nécessaire.
Montserrat est référencée dans la pile de polices mais n'est pas fournie ni téléchargée : le navigateur utilise la police système lorsqu'elle n'est pas disponible. Aucun transfert de police distante depuis l'administration.
