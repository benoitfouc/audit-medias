# Audit Médias v2.3.4

Une interface plus simple, sans modifier le moteur d'analyse ni les protections de suppression.

- Onglet **Médias** centré sur les familles ; ancien inventaire conservé dans **Réglages > Technique / diagnostic**.
- En-tête compact, explications répétées retirées, filtres et réglages avancés repliables.
- Actions groupées en haut et en bas, synchronisées et protégées contre un double lancement.
- Recherche manuelle des mises à jour dans les réglages, sans installation forcée.

Les réglages et résultats existants sont conservés. Aucun nouvel audit n'est imposé depuis 2.3.3.

**Installation :** utiliser exclusivement `audit-medias-v2.3.4.zip`, jamais **Source code (zip)**.
Pour tester la proposition de mise à jour, conserver 2.3.3 sur le site pilote et consulter **Tableau de bord > Mises à jour** après publication. Le cache du client 2.3.3 peut retarder la détection jusqu'à son prochain renouvellement.

Sauvegarder avant déploiement ; aucune référence détectée ne garantit pas qu'une image est inutilisée.
